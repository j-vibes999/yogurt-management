# Yogurt Manager project guidance

For UI/UX work, read `PRODUCT.md`, `DESIGN.md`, and `.interface-design/system.md` before editing. Use the established Lao-first operations design and approved category colors.

Choose the relevant installed skills:

- `interface-design` for page hierarchy, consistent components, and layout.
- `impeccable` for focused color, typography, layout, copy, and state refinement. Run its context command from this repository and pass the target source path. Use the matching surface brief for mode and purpose.
- `product-design-and-ux` for changes to task flows, role handoffs, recovery, or completion behavior.
- `web-design-guidelines` for final interface review, fetching its current upstream rules.
- Existing `frontend-design`, `emil-design-eng`, and `mobile-native` cover implementation and platform details. Use `ui-ux-pro-max` for targeted reference queries when useful.

Project decisions in `DESIGN.md` take precedence over generic skill defaults. Reuse the current custom CSS and accessible components. Preserve business logic during visual refinement and report the actual scope of verification. Existing user authorization and preferences govern the task.
